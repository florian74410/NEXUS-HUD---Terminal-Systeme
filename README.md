# N3XV5 Terminal HUD — Electric Pulse DEV 1.4.1

**Vrai terminal multi-connexion Linux** (PySide6/QTermWidget + tmux). Refonte visuelle avec les 53 assets vectoriels/animés issus du pack de l'utilisateur `Assets_Theme_NEXUS`.

Fonctionnalités : split multi-terminal redimensionnable, SSH/clé Ed25519, commandes rapides + variables du profil, suggestions Ctrl+Espace, sessions tmux, appairage LAN à confirmation bilatérale (opt-in), Smart Hover.

Voir [README-V1.4.1.md](README-V1.4.1.md) pour l'audit, la correspondance des assets, l'installation et les limites de validation.

```bash
bash setup-dependency.sh
bash start-nexus.sh
```

Aucune dépendance fonctionnelle avec N3XV5 HUB ou IATB-CLI.
